Система повышений
MEDIA

Media

Начальный уровень
  • Снять 2–3 Shorts о сервере
  • Выложить в TikTok / YouTube Shorts (мин. 50 просмотров)
  • Указать IP сервера в описании
  • Без водяных знаков

Senior Media

Продвинутый
  • 5+ Shorts на канале
  • 1 Shorts с 500+ просмотров
  • Активно отвечать в комментариях
  • Помогать новым медиа

Admin Media

Руководство
  • 25+ качественных Shorts
  • Управлять командой медиа
  • Организовывать конкурсы
  • Связь с кураторами
MODERATION

Helper

Испытательный
  • Знать /mute, /kick
  • Обработать 5+ жалоб
  • Быть вежливым в чате
  • Онлайн: 2+ часа в день

Senior Helper

Опытный
  • 10+ закрытых тикетов
  • Правильно применять /ban
  • Сообщать о багах
  • Наставлять новых хелперов

Moderator

Основной состав
  • Доступ к /ban
  • 20+ наказаний в неделю
  • Проверять логи
  • Следить за читерами

Senior Moderator

Доверенный
  • 5+ апелляций
  • Обучать модераторов
  • Выявлять твинки
  • Помогать кураторам

Head Moderator

Руководство
  • Курировать модерацию
  • Одобрять баны
  • Создавать регламенты
  • Встречи с кураторами

Media Curator

Гибрид
  • Курировать медиа
  • Проверять заявки
  • Управлять составом медиа
  • Работа с Admin Media

Curator

Высший
  • Полное управление сервером
  • Назначать кураторов
  • Финальное решение по банам
  • Политика повышений
